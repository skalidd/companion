# Credits & how this was built

**Companion was vibe-coded.** Every line of it was written in conversation
with a local LLM — a quantized model running on the same machine the system
runs on, not an API.

To be exact about it, because being exact about it is the whole point of the
project: the code was generated by the model, but the *decisions* were not.
When a claim about why something was broken didn't survive inspection, it was
thrown out. The compaction bug was finally diagnosed by capturing the actual
HTTP request on the wire and reading the bytes, not by trusting a confident
explanation. Several confident explanations did not survive that. The failure
modes documented in `docs/ARCHITECTURE.md` are all things that actually
happened on a real machine, usually more than once.

So: AI-written, human-verified, both of us wrong often enough that the guards
exist.

If you are reading this wondering whether vibe-coded software is trustworthy —
that is exactly the question the honesty rules in `data/prompt.md` exist to
keep the *running system* from answering badly. Same problem, both ends.

- Human: skalidd — wanted memory in Open WebUI, got it, then packaged it.
- Model: the local model, on the same hardware, sharing RAM with the thing it
  was helping build. It would like it noted that it did not write the
  gotchas table from imagination.

No cloud services were used in *running* this. The making was mostly local
too, with one honest exception: a web search to confirm the exact Hugging
Face repo name for the summarizer model, rather than trusting the model's
recollection of it.
